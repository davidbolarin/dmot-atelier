# D'Mot Atelier website

Open the `site` folder in VS Code. For a live preview, install the "Live Server" extension, right-click `index.html` and choose "Open with Live Server".

- `index.html` - page content
- `css/style.css` - all styling (colours are the variables at the top)
- `js/script.js` - size picker, sound buttons, theme toggle and email box
- `assets/` - logo, t-shirt image, videos and their preview images

Fonts are system fonts (set by `--serif` and `--sans` at the top of `css/style.css`), so nothing is loaded from the internet.
